# juryoku-hikkoshi

Browser physics game: move furniture into a room while gravity rotates.

重力引越: 引っ越し業者として、トラックの荷台から部屋へ家具を運び込む。重力の向きは約9秒ごとに上下左右へ変わる。

## 遊び方

`index.html` をブラウザで開く（ビルド不要、`file://` で動く。Matter.js 0.20.0 は `vendor/` に同梱）。

- 家具をドラッグして、荷台（左）からドア（左下）を通して部屋（右の正方形）へ運ぶ
- ダブルクリック（スマホはタップ）でロープ固定・解除。重力が変わるたびに2本まで使える
- 切替3秒前に画面の縁が光り、大きな矢印で次の向きを予告する
- 60秒の時間切れ時点で、部屋の中で止まっている家具だけが「運び込めた」扱い
- 結果は「大家さんからの請求書」（運搬報酬 − 被害額）。事故リプレイ、画像シェア、即リトライあり
- 「今日の現場 No.N」は JST の日付で決まるシード（2026-11-01 が No.1）。家具の順番と重力の変化が全員同じになる

## 方針（参考にした OSS と採った方式）

実装前に Matter.js 公式リポジトリの examples を読んだ。`gyro.js` は `engine.gravity.x/y` を書き換えて重力の向きを変え、`substep.js` は Runner の delta を 1000/600ms に下げて薄い剛体のすり抜けを抑え、`sleeping.js` は `enableSleeping` を使い、どの例も `MouseConstraint`（stiffness 0.2）でつかむ。GitHub で Matter.js のゲーム例も検索したが、ヒットしなかった。そこで本作は、これらの考え方を組み合わせて自前で書いた（コードはコピーしていない）。主な仕組みは次のとおり。

- 時間の進め方: Runner は使わず、1/240 秒の固定ステップを自前のアキュムレータで1フレームに複数回まわす
- 重力の切替: `engine.gravity` を書き換え、全剛体に `Sleeping.set(body, false)` をかける
- つかんでいる間: `beforeUpdate` で重力を打ち消す力を加える。重い家具ほど打ち消しを弱め（sag）、拘束の stiffness も下げる
- すり抜け対策: 外壁を厚くし、`afterUpdate` で速度に上限をかける。拘束は位置を直接動かすので、1サブステップの移動量にも上限をかける。指が家具から 90 以上離れたら手を離す

物理と採点は `src/rules.js`（純粋関数）と `src/sim.js`（Matter のみ、DOM なし）に分けた。描画は記録したスナップショットだけを入力にするので、プレイ中の画面とリプレイは同じ関数で描いている。

ドアは「重力がドア側（左）を向いている間だけ閉まる」方式にした。ただし家具がドアに挟まっている間は閉めない。

## ファイル

| パス | 内容 |
| --- | --- |
| `src/rules.js` | シード乱数、重力列（同じ向きを連続させない）、日替わり番号、被害クールダウン、判定、請求書、実績 |
| `src/sim.js` | Matter のワールド、家具、固定ステップ、被害検出、ロープ、トラック、記録、ステージ進行 |
| `src/render.js` | Canvas 描画（ライブとリプレイ共通） |
| `src/app.js` | 画面遷移、MouseConstraint、タップ/ダブルクリック、ポーズ、結果、リプレイ |
| `src/share.js` | 請求書画像の生成（`document.fonts.ready` を待つ）、Web Share API、画像保存と X 投稿 |
| `src/audio.js` | WebAudio で合成した衝突音・割れる音・予告音 |
| `src/i18n.js` | 英語キーと日本語辞書（デフォルトは ja） |
| `src/storage.js` | localStorage（すべて try/catch）: 最高額、実績、チュートリアル済み |

## テスト

```sh
npm test   # = node --test test/*.test.js （依存パッケージなし）
```

テストは本体の定数を流用せず、テスト側のリテラル設定で結果を確かめる。対象は次のとおり。

- 重力列: 同じ向きが連続しない、同じシードなら列が一致する
- スリープ: 寝ている剛体が重力切替後に動く
- すり抜け: 速い小物を壁に押し付け続ける、つかんで壁の向こうへ引っ張る
- 判定: 静止判定と部屋内判定
- 被害: 0.5 秒クールダウン、金魚鉢が割れる
- ステージ進行: 9 秒間隔と 3 秒前予告、初回の 10 秒猶予、荷台の上限待ち、ロープの本数制限、請求書と実績

## 既知の課題 / 次の候補

- スマホ縦画面では、ワールド（荷台＋部屋）が横長なので盤面が小さい。次の候補は縦画面専用の配置（荷台を部屋の下に置く）
- 日替わりの同一性は、同じブラウザ・同じ操作なら再現する程度。端末間で浮動小数点の結果が完全に一致する保証はない
- 次段階の候補: 動画シェア（MediaRecorder）、45 度重力モード、家具の追加（本棚、観葉植物）
