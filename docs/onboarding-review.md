## 分かりにくかった点

1. ゴールが分からない。荷台・ドア・部屋に名前も目印もない。スマホ縦ではドアが仕切りの左端の細い隙間で、気づきにくい
2. 家具をまっすぐ部屋へ引くと、仕切りの壁に当たって入らない（スマホ縦で 0/14）。家具 → ドア → 部屋という経路が見えない
3. 何をすればいいかの合図がない。最初の家具が出ても「ドラッグする」ことを示すものがない
4. 今日の現場 No.27 では最初の家具が冷蔵庫で、速く引くと理由の説明なしに「手がすべった」と出る。重い家具ほどゆっくり引く必要があることが分からない
5. HUD に得点がない。「被害」が増えるだけで、運び込めた数も見込みの金額も出ない。「荷台 12」の意味も分かりにくい
6. HUD のロープ表示が「×××」で、ロープの残り本数に見えない
7. 重力切替の説明は小さな文章の帯で、読む前に切り替わる。どちらへ変わるかの文字がない
8. スマホ縦では HUD が 2 行に折り返し、一時停止ボタンだけが 2 行目に落ちる
9. 結果画面の金額 2 列に見出しがない（報酬か被害か分からない）。運び込めなかった理由（荷台に残った、部屋の外、止まっていない、割れた）が分からない
10. タイトルの説明文はロープの細かい条件が中心で、肝心の「部屋に運ぶ → 重力が変わる → 止まっていれば得点」の流れが伝わらない

## 直したこと

| # | 分かりにくかった点 | 直したこと |
| --- | --- | --- |
| 1 | ゴールが分からない | 荷台・ドア・部屋に名前を常に描く。最初の家具が部屋で止まるまで、部屋の枠を点滅させ「ここへ運ぶ」を出す |
| 2 | まっすぐ引くと壁に当たる | 同じ間、荷台 → ドア → 部屋の経路を破線の矢印で描く。タイトル 1 コマ目も同じ経路の図 |
| 3 | ドラッグの合図がない | そのゲームで最初につかむまで、荷台の家具に手の印と「ここをドラッグ」 |
| 4 | 「手がすべった」の理由が分からない | 文言を「手がすべった。重い家具はゆっくり引く」に |
| 5 | HUD に得点がない | 「被害」「荷台」をやめ、「運び込み n/14」と「見込み ¥」（いま時間切れなら払われる額。最終請求と同じ判定）を出す。被害が出たら見込み額が赤く光る。部屋の端で揺れる家具で表示がちらつかないよう、300ms 続いた値だけを出す |
| 6 | ロープ表示が「×××」 | 残り本数を数字で出す |
| 7 | 重力切替の説明が小さい | 予告の矢印の下に「重力が上へ」を大きく。最初の予告（2 ゲームまで）は 2 行目に「家具は矢印の向きへ落ちる」 |
| 8 | スマホで HUD が 2 行 | 狭い画面ではラベルを値の上に置き 1 行に収める（360/390px で最大桁の値を入れても高さが変わらないことを確認） |
| 9 | 結果の列に見出しがない、理由が分からない | 列見出し（品目 / 報酬 / 被害）、報酬の条件の一文、報酬にならなかった家具の内訳（荷台に残った / 部屋の外 / 止まっていない / 割れた） |
| 10 | タイトルの説明文 | 3 コマの図（ドラッグしてドアから部屋へ → 重力が変わる → 60 秒後に止まっていれば報酬）と一行の注意に置き換えた |
| - | ロープ | 最初の家具が部屋で止まったとき、ロープを一度も使っていなければ、その家具を丸で囲み「長押しでロープ固定」（PC はダブルクリック）。重力切替の直後 1.5 秒は出さない |
