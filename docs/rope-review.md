# ロープを見えるボタンにする（2026-11-27、公開版 7a0b43c）

オーナーの声: 「ロープの使い方や操作のしかたが分からない」。前回は手の印と「ここを長押し / ここをダブルクリック」を足したが、操作そのものが見えないジェスチャーのままだった。

## 直す前（公開版 3edbc35）

- ロープはダブルクリック（スマホは長押し）か、HUD のロープボタンを押してから家具をタップする。どれも画面に形がない
- HUD のロープは「ロープ 3」と数字だけ
- 固定できないときは、画面下のトーストで理由が出る。家具の近くではない

スクショ: `docs/screenshots/rope/before-{pc,sp}-rope-step.png`（練習のロープの段階）、`before-{pc,sp}-job.png`

## 直したこと

| 方針 | 直したこと |
| --- | --- |
| その場の「固定」ボタン | 部屋の中で止まり、床か壁に接している家具の上に「固定」ボタン（鍵のアイコン付き、黄色）を出す。押せば固定。固定済みの家具には「外す」（白）を出す。大きさは 84x44 CSS px で、スマホでも同じ。重力が上向きのときは家具の下側（空いている側）に出す。ほかのボタンと重なる位置には出さない |
| ロープが残っていないとき | ボタンを灰色にし、押すと「ロープは同時に3つまで。どれかを外す」をその家具の近くに出す |
| 固定できない家具を触ったとき | ボタンのない家具をタップ / クリックすると、理由をその家具の上に出す。「部屋に入れて止めると固定できる」「止まると固定できる」「床か壁につけると固定できる」 |
| 操作の凡例 | HUD のすぐ下に常に出す。左に枠付きの「ドラッグ」チップと「運ぶ」、右に黄色の「固定」チップ（ボタンと同じ見た目）と「重力が変わっても動かない（同時に3つまで）」 |
| HUD のロープ残数 | 「ロープ 残り3」 |
| 初回練習 | ロープの段階は「段ボールの上の『固定』を押す」。段ボールの「固定」ボタンが点滅し、押すと重力が変わる段階に進む |
| そのほか | 固定した瞬間の「固定: 落ちない・壊れない」は各ゲームの最初の 1 回だけ。続けて固定しても文字が重ならない。重力の予告の文字は家具のない側に出し、ボタンで隠れないようにした |

ダブルクリックと長押しは残している。画面では説明していない。

## 説明文を読まずにロープを使えるか

使えると判断した。理由は次の 3 つ。

- 段ボールが部屋で止まった瞬間、その真上に「固定」と書いた黄色いボタンが出て、練習中は点滅する。押す場所と押せる時点が画面に出る（`after-*-2tie-button.png`）
- 押せば普通のボタンと同じく 1 回で固定され、ボタンは「外す」に変わり、HUD は「残り2」に減る（`after-*-3tied.png`）。続く重力の変化で、固定した段ボールだけが動かず被害も ¥0 になる（`after-*-4switch.png`）
- 押せないときは、触った家具のすぐ上に理由が出る（`after-*-5reason.png`）

凡例の黄色い「固定」チップは、ボタンと同じ見た目にしてある。一度ボタンを見れば、本番でも何のボタンか分かる。

ただし、ここで確かめたのはスクリプトの操作で、人が初見で遊んだ結果ではない。

## 確認

公開 URL を記録なし（localStorage 空）で、PC 1280x800 とスマホ 390x844 で最初から遊んだ。

- ブラウザ確認 13 項目が、PC・スマホともすべて成功
  - 凡例が出る
  - HUD が「残り3」
  - 荷台の上ではボタンが出ない
  - 部屋で止まると「固定」ボタンが段ボールの上に出る（84x44）
  - 押すと固定され「外す」に変わり「残り2」
  - 重力が変わっても段ボールは部屋に残り被害 0
  - 本番で荷台の家具をタップすると、その近くに「部屋に入れて止めると固定できる」が出る
- 直す前の公開版で同じ確認を流すと、凡例・「残り3」・「固定」ボタンの 3 項目で失敗した
- 4 個を部屋に置いた本番: 「固定」は 4 個に出る。3 個固定すると「外す」3 個と灰色の「固定」1 個になり、灰色を押すと「ロープは同時に3つまで。どれかを外す」が出る（`after-pc-many.png`）
- `npm test`: 60 件すべて成功。新規の 2 件（ボタンを出す条件、固定できない理由）は、実装前に失敗することを確かめた
- HUD は 360 / 390 / 1280 幅で 1 行のまま。横長画面のヒントの帯は、荷台と部屋の名前にも重力の矢印にも重ならない
