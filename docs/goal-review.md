# 目的とロープを伝える（2026-11-27、公開版 3d243df）

オーナーの声: 「何をすればいいか（目的）が分からない」「ロープの使い方も分からない」。

## 直す前（公開版 992f890）

- タイトルの 3 コマ図を読み飛ばすと、ボタンを押した瞬間に時計が動き出す。何を目指すかを確かめる間がない
- 得点の手がかりは HUD の「運び込み」と「見込み」の数字だけ。部屋に入れた家具そのものには何も起きないので、「部屋で止めると報酬」という結びつきが画面の中で見えない
- ロープは、最初の家具が止まったときの文字のヒントと点線の丸だけ。どこを押せばいいのか、使うと何が良くなるのかが見えない

スクショ: `docs/screenshots/goal/before-{pc,sp}-*.png`（公開版 992f890、記録なしの状態）

## 直したこと

| 課題 | 直したこと |
| --- | --- |
| 始まった瞬間に目的がつかめない | 毎回、開始直前に「依頼書」を 1 枚出す。図（荷台の段ボール → ドア → 部屋で緑のチェックと +¥）と「60秒で、荷台の家具を部屋へ運び込め」、「部屋の中で止まっている家具だけが報酬になる。全部で14個、最大¥47,200」。タップかクリックで閉じるまで時計は進まない |
| 体で覚える機会がない | 初回だけ、段ボール 1 個の練習を挟む。運ぶ → ロープで固定する（固定しないと先へ進まない）→ 重力が変わっても動かないのを見る → 「練習完了」の 1 枚 → 本番。練習はとばせる |
| 何が得点かが遊んでいて見えない | 部屋で止まった家具に緑のチェック。初めて止まった瞬間に、その場で「+¥1,200」のような金額が浮かぶ |
| ロープの使い方が分からない | 対象の家具に手の印と「ここを長押し」（PC は「ここをダブルクリック」）を描く。練習でも本番のヒントでも同じ |
| ロープの効き目が分からない | 固定した瞬間と、練習で重力が変わった瞬間に、その家具の上に「固定: 落ちない・壊れない」を出す |
| HUD の時間の単位 | 「57.6秒」のように単位を付けた。練習中は「練習」と出す |

依頼書の後ろには現場（荷台・ドア・部屋とここへ運ぶの経路）がうっすら見えるので、閉じたときに図と同じ場所がそのまま目の前にある。

## 最初の何秒で目的が伝わるか

公開 URL を記録なし（localStorage 空）で最初から遊んだ時間（スクリプトによる操作、ページを開いた時点から）:

| 時点 | PC 1280x800 | スマホ 390x844 | 画面 |
| --- | --- | --- | --- |
| 練習の依頼書（目的と図） | 2.2 秒 | 1.8 秒 | `after-*-1order.png` |
| 段ボールが部屋で止まり「+¥1,200」と緑のチェック | 8.1 秒 | 8.1 秒 | `after-*-3paid.png` |
| 手の印で「ここをダブルクリック / ここを長押し」 | 9.4 秒ごろ | 9.4 秒ごろ | `after-*-3b-rope-pointer.png` |
| 固定して「固定: 落ちない・壊れない」 | 9.7 秒 | 10.5 秒 | `after-*-4roped.png` |
| 重力が変わっても段ボールは動かず、被害 ¥0 | 16.2 秒 | 16.7 秒 | `after-*-5switch.png` |
| 練習完了の 1 枚 | 18.1 秒 | 18.7 秒 | `after-*-6done.png` |
| 本番開始 | 20.6 秒 | 21.2 秒 | `after-*-7job.png` |

目的（荷台の家具を部屋へ、止まっていれば報酬）は、ボタンを押した直後、時計が動く前の 1 枚で伝わる。そのうえで約 8 秒で「部屋で止まる → お金が入る」を、約 10 秒でロープを、約 16 秒でロープの効き目を、自分の手で確かめられる。2 回目以降は練習が出ず、依頼書 1 枚（`after-*-0order-job.png`）だけになる。

依頼書を読まなくても「この家具を、この部屋に入れる」が分かるかは、依頼書を閉じた直後の画面（`after-sp-2practice-drag.png`）で確かめた。段ボールに手の印と「ここをドラッグ」、部屋に点滅する枠と「ここへ運ぶ」、その間にドアを通る矢印が出ている。

## テスト

- `npm test`: 58 件すべて成功。新規 3 件（練習用の重力切替 `queueSwitch`、チェックと金額はライブだけでリプレイには出ない、ロープの対象に手と文言を描く）は、実装前に失敗することを確かめた
- ブラウザ（公開 URL、Playwright + Chrome、PC 1280x800 とスマホ 390x844）で、初回の流れを 13 項目確かめ、すべて成功:
  - 依頼書が出ている間は時計が 0 のまま
  - 1 回のタップで閉じる
  - 運ぶとロープの段階に進む
  - ダブルクリック / 長押しで固定できる
  - 重力が変わっても固定した段ボールは部屋に残り、被害 0
  - 練習完了の 1 枚が出て、本番は 14 個で始まる
  - 2 回目以降は依頼書だけ
  - 「練習をとばす」は練習のときだけ出る
- 直す前の公開版で同じスクリプトを流すと、最初の項目（依頼書が出て時計が止まっている）で失敗する
- HUD は 360 / 390 / 1280 幅で 1 行のまま。横長画面のヒントの帯は、荷台と部屋の名前にも重力の矢印にも重ならない
